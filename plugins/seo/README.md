# SEO

Plugin Codex con 53 skills y 20 herramientas MCP. La sección Google incluye Analytics, Search Console y Business Profile con perfiles conjuntos y credenciales aisladas por servicio y cuenta.

El dashboard se inicia con `npm run dashboard`. Lee auditorías desde `SEO_PLUGIN_DATA_DIR` o, por defecto, `~/Documents/seo-plugin/.seo-data`.
